# 拼豆拆分 Web 工具（一起拼豆配套）

把任意图片转成拼豆像素画：上传 → 正方形框选（非 1:1 时以最短边为边长，可拖动）→
池化到 24/72/216 → 映射到设备端 36 色水彩笔色板 → 输出对照拼图 + 设备端 `.bead` 成品包。

## 运行

```bash
cd scripts/beads_web
python app.py
```

自动打开浏览器 http://127.0.0.1:5000（Python 3.10+，依赖 `pip install -r requirements.txt`）。

## 输出

下载 zip（`beads_<作品名>_<N>.zip`）内含：

```
beads/          # .bead 成品数据，解压后整体拷入 SD 卡 /sdcard/User/Beads/
                #   N=24 : 1 个 B1
                #   N=72 : 1 个 B2 + 9 个 B1
                #   N=216: 1 个 B3 + 9 个 B2 + 81 个 B1
images/         # 对照拼图：
                #   overview_<N>.png  整幅总览（分块线）
                #   B1_*.png         24×24 块对照图，每格标设备 6×6 色卡坐标（行-列）
                #   B2_*.png         72×72 块辅助图
palette_36.png  # 36 色卡说明（色号 + 色卡坐标）
README.txt      # 设备端导入说明
```

`.bead` 文件格式与设备端 `main/apps/beads/beads_storage.cc` 完全一致
（`BEAD` magic + level + w/h 小端 + 像素字节，色号 1..36）。
B3/B2/B1 由同一张 N×N 色号矩阵切片派生，层级内容严格一致。

## 转换说明

- 池化：浮点边界加权面积平均（平均池化），非整数比例不丢边
- 量化：RGB 欧氏距离最近邻映射到 36 色水彩笔色板
- 1:1 图片跳过框选直接用全图；非 1:1 默认取中心正方形

## 限制

- 作品名仅 ASCII（1~20 字符），与设备端 26 键键盘一致
- 透明底图片按黑底处理，建议用白底图
- 单边超过 8192px 的图会先等比缩小再裁剪（裁剪精度略有损失）
- 36 色水彩笔色板对照片类图色偏明显，建议选色块对比度高的图
