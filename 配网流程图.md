# 小智 ESP32 设备配网 + 激活流程图

## 一、设备端启动流程

```
┌─────────────────────────────────────────────────────────────────────┐
│                        设备上电 / 复位                               │
└──────────────────────────┬──────────────────────────────────────────┘
                           │
                           ▼
┌──────────────────────────────────────────────────────────────────────┐
│ 1. Bootloader                                                       │

└──────────────────────────┬───────────────────────────────────────────┘
                           │
                           ▼
┌──────────────────────────────────────────────────────────────────────┐
│ 2. ESP-Hosted 初始化                                                 │
│    - SDIO 连接 C6 协处理器 (CLK=18, CMD=19, D0-D3=14-17)            │

                           │
                           ▼
┌──────────────────────────────────────────────────────────────────────┐

│    - SD 卡挂载 (SDMMC Slot 0)  ←── 与 C6 WiFi 共享 SDMMC            │
└──────────────────────────┬───────────────────────────────────────────┘
                           │
                           ▼
┌──────────────────────────────────────────────────────────────────────┐
│ 4. Application::Start()                                             │
│    - 状态: kDeviceStateStarting                                      │

└──────────────────────────┬───────────────────────────────────────────┘
                           │
                           ▼
                   ┌───────────────┐
                   │ 有已保存 SSID? │
                   └───┬───────┬───┘
                 NO    │       │    YES
                       ▼       ▼
┌──────────────────────────┐  ┌──────────────────────────────────────┐
│ 5a. AP 配网模式          │  │ 5b. Station 直连模式                  │

│ - DNS 劫持 (Captive)     │  │                                        │

│                          │                     │

│  POST /scan ← 扫描WiFi   │  ┌──────────────────────────────────────┐
│  POST /submit ← 提交密码 │  │ 6. OTA 版本检查                      │
│  POST /exit ← 退出配网   │  │    POST {CONFIG_OTA_URL}             │
│                          │  │    Body: {version, board, mac, uuid}  │
│  (小程序直接跟设备通信)    │  │    Response:                         │
│                          │  │    {                                 │
│  配网完成 → 停 AP         │  │      firmware: {version, url}        │
└──────────┬───────────────┘  │      websocket: {url, token}  ← 或 mqtt
           │                  │      server_time: {...}               │
           ▼                  │    }                                 │

                              └──────────────────┬───────────────────┘
                                                 │
                                                 ▼
                              ┌──────────────────────────────────────┐

                              └──────────────────┬───────────────────┘
                                                 │
                                                 ▼
```

## 四、小程序后端 vs 设备直连

```
┌─────────────────────────────────────────────────────────────────┐
│                    当前方案 (Web 页面)                           │
│                                                                 │
│  手机 ──WiFi──▶ ESP32热点(192.168.4.1) ──Web页面──▶ /scan       │
│                 (ESP32 自己扫描WiFi, 返回列表给手机浏览器)         │
│                                                                │
│  手机浏览器  ──POST /connect──▶ 测试连接                         │
│  手机浏览器  ──POST /save─────▶ 保存SSID                         │
│  手机浏览器  ──POST /reboot───▶ 重启设备                          │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│                    小程序方案 (新)                                │
│                                                                 │
│  手机 ──WiFi──▶ ESP32热点(192.168.4.1)                          │
│     │                                                           │
│     ├── GET  /scan   ──▶ ESP32 扫描WiFi, 返回列表                │
│     ├── POST /submit ──▶ 发送选中的SSID+密码                     │
│     └── POST /exit   ──▶ 退出配网, 切Station                     │
│                                                                 │
│  关键区别: 不需要重启! 不需要网页!                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 五、各端点详情

| 端点 | 方法 | 请求 | 响应 | 作用 |
|---|---|---|---|---|
| `/scan` | GET | - | `{"networks":[{ssid,rssi,authmode}]}` | 扫描WiFi |
| `/submit` | POST | `{"ssid":"xxx","password":"xxx"}` | `{"success":true}` | 配网 |
| `/exit` | POST | - | - | 退出配网 |
| OTA URL | POST | `{"application":{...},"board":{...},"uuid":"..."}` | `{"firmware":{...},"websocket":{...},"server_time":{...}}` | 版本检查+获取后端地址 |
