# 数智方舟 · 产品亮点汇报

## 一句话介绍

> **一张图片,十分钟,让你喜欢的角色睁开眼睛、开口说话、看得见你,甚至摸得到你。**

*(你的原句也很好,建议把"触碰到你"改为"摸得到你"或"摸到你的指尖",更顺口也更准确——角色在屏幕里,是"你摸到它")*

---

## 五大核心亮点

### 亮点一:一张图,复活你的角色(极低门槛 + 自动化管线)

- 上传**任意一张角色立绘**,10 分钟全自动完成:AI 拆解图层 → 动态化 → 生成会眨眼、会呼吸、会说话的 Live2D 动态立绘
- 全流程网页一键操作,无需任何绘画/建模/编程基础
- 明日方舟 400+ 干员公共角色库,一键克隆即可拥有;未收录的角色自己做一张图就能诞生

### 亮点二:像真人一样的对话(角色扮演 + 原声克隆)

- 每个角色有独立**人设提示词**(记忆、性格、世界观),聊天像真的在和凯尔希斗嘴、和德克萨斯搭话
- **克隆原 CV 音色**:上传 3~10 秒干员语音,AI 克隆音色,开口就是熟悉的声音
- 喊名字语音唤醒("你好凯尔希"),真·打招呼式互动

### 亮点三:看得见、摸得到的陪伴(实体硬件互动)

- 不只在手机/电脑里——角色跑在**实体触屏设备**上,摆在桌上
- **摸头会眯眼笑、手指划过视线会跟着走、说话时表情实时联动**——博士与干员之间隔着屏幕的距离感消失了
- 待机时角色会自己晃头、眨眼、四处张望,像桌面上养了个活物

### 亮点四:极高的自定义(你的岛,你做主)

- 人设、音色、唤醒词、时装皮肤、背景场景(33 张官方场景长图)、Q 版形态……全部可换
- 竖屏立绘 / 横屏立牌 / Q 版纸偶 / 多形态切换,一个角色多种玩法
- 多用户体系:每个玩家有自己的仓库、自己的角色、自己的配额

### 亮点五:开箱即用 + 持续生长(产品化能力)

- 设备开机绑定即用,角色资源云端同步、断点续传、增量更新,无需折腾
- 资源制作网页已适配手机端,随时随地做角色
- 从"一个玩家"到"一个班级/社团":多用户、管理员验收、公共库共享——天生适合作为**可持续运营的产品**

# 用户使用指南(保姆级,跟着做就能成功)

> 面向零基础用户:每一步都写清楚"点哪里、看到什么、下一步做什么"。

## 一、第一次开机:联网,和角色见面

1. **插卡**:把 8G SD 卡插入设备卡槽
2. **开机**:按一下设备右侧**从下往上数第二个圆形按钮**(以图片里三角形挂链为上端来判断方向),电源键亮红色
3. **打开微信**:下拉搜索框,输入"数智方舟",点击进入小程序/公众号
4. **登录/注册**:授权登录;设备背面的右上角贴纸上有二维码,微信扫码
5. **连接 WiFi**:登录后自动弹出联网界面,框框里有两行——一行填 WiFi 名称,一行填密码(密码自动保存,下次不用再输);下面有"确认连接"按钮
   - 点击后出现环形进度条,显示 3、2、1 倒计时,提示"连接成功"或"连接失败"
   - 失败的话会出现"重新连接"按钮,再点一次即可
6. **连接成功后**,页面提示:"您现在可以前往设备,设备端将显示默认的角色展示页面,如需添加额外角色,请点击下面的按钮"
7. **看设备屏幕**:此时进入默认角色的**通行证竖屏展示页面**(一张会动的立绘)
8. **去对话**:点击屏幕右上角"前往对话",进入对话页面(角色互动展示页面)
9. **打招呼**:屏幕上方出现一块 80% 透明的提示条——"请说'凯尔希'开始对话";对着设备喊"凯尔希",角色就会回应你
10. **返回展示**:点击原来位置的"回到展示模式",就回到动态展示页

## 二、切换角色(换一个干员陪你)

1. 在动态展示页,点击右上角**"切换角色"**按钮,进入角色选择页
2. 页面最上方有**两个筛选按钮**:点开后选择职业和稀有度(6 星到 1 星),筛选结果实时显示在下方;每页展示 12 个角色,**左右滑动可以翻页**
3. 找到想换的干员,点击它的**缩略图**,屏幕正下方会出现绿色的**"确认"**按钮
4. 如果这个角色已经下载到 SD 卡里:直接加载,加载过程中有百分比进度条和转圈圈动画
5. 如果没有下载过:弹出窗口"当前角色未缓存,是否下载完整角色资源",下方两个按钮:**"确认(大概 X 分钟)"** 和 **"取消"**
6. 等加载/下载完成,切换就成功了

## 三、DIY 角色形象(一张图做出会动的她)

1. 手机/电脑打开资源生成主页(云服务器地址),进入**资源生成总页**
2. 主页有三个功能板块,点击**"制作角色形象"**
3. 页面提示"请将角色的静态立绘拖到此处"——把准备好的图片拖进去(也可以点击选择文件),然后点"下一步"
4. 进入框选页面:**用手指/鼠标在角色主体周围画一个框**(把角色整个框住);如果不想框选,直接点"下一步",会弹提示"确认不进行 ROI 框选?"——确认后使用整张图片
5. 点击"框选完成 → 开始并发生成"按钮,提示"同时生成三个角色模型,请等待"
6. 状态页有三个模型生成信息栏,会显示"running(生成中)""success(成功)""fail(失败)"三种状态;**三个都出现 success 或 fail 后**,下面的"下一步"按钮才会从灰色变绿色,点击进入
7. 构建和检测是**自动的**,等待完成,会看到三个模型在通行证中的预览效果——**三选一**,选出最满意的一张,点"下一步"
8. 右侧出现参数条,可以实时调整模型各个部分;最右侧有 **AI 助手**,哪里不满意**用大白话告诉它**(比如"头发再飘一点"),它会帮你改
9. 下方有 PSD 预览器,可以拖动调整图层位置
10. 满意后点击**"导出角色到个人仓库"**——角色自动保存到你的云端空间,之后就能给它配人设和音色

## 四、DIY 角色音色、性格、知识库

1. 手机/电脑打开后台,注册/登录(手机号或邮箱)
2. 进入**角色管理页面**:
   - **创建角色**:点页面右上角"➕ 创建角色",填写角色名、唤醒词拼音、人设提示词,保存
   - **克隆音色**:进入"音色管理"页,上传干员 3~10 秒原声录音,AI 自动克隆(约 10 秒),回到角色页下拉选择
   - **配置知识库**:在"知识库"页新建条目(世界观、人物关系等),绑定到角色
   - **绑定画面资源**:填写资源路径(系统有提示的三种写法),角色唤醒后设备会切换到对应画面
3. 保存后,设备端喊角色的唤醒词,就能用新音色、新人设和你聊天

## 五、其他亮点玩法(简单步骤)

| 功能 | 怎么玩 |
|---|---|
| **摸头互动** | 对话页里**按住角色头部 1.4 秒**,她会眯眼笑 |
| **视线跟随** | 手指在屏幕上移动,**角色的眼睛会跟着看** |
| **背景系统** | 对话页点"解锁背景"→ 检查/下载官方场景背景 → **左右滑动看全景**;点"切换背景"换场景(视野/夜幕/山岳等 33 张) |
| **时装** | 展示页点"时装"按钮,列表选择皮肤 |
| **Q 版形态** | 对话页点"PPD交互",Q 版纸偶小人陪你玩 |
| **一键克隆公共角色** | 角色选择页点未拥有的干员 → "克隆并下载",一步到位 |
| **换绑账号** | 后台重新绑定设备 → 设备自动清理旧角色资源,重新下载,无需手动删文件 |

## 附录:常见问题

- **屏幕卡住不动?** 长按电源键重启设备,重新联网即可(角色资源不会丢)
- **角色列表是空的?** 首次使用会先同步角色缩略图(有进度条,约 4-5 分钟,期间不可操作,完成后会提示);之后秒开
- **上传文件报错?** 只支持资源类文件(图片/模型/音频等),单文件不超过 100MB,仓库总空间 2GB,可在后台"仓库用量"查看
- **对话没反应?** 确认设备已联网、喊的是角色设定的唤醒词(如"凯尔希")、音量正常
