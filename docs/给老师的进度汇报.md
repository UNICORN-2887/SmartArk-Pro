# 给晏老师的进度汇报

---

晏老师,教师节快乐!🎉 谢谢您一直关心我们的项目,借这个机会向您汇报一下最近的进展。

## 一、一键生成问题:完全解决了 ✅

之前最头疼的"一张图自动生成动态角色"成功率不稳定,这段时间我们把整个流程重新梳理了一遍,找到了根本原因:**环节太多、误差层层叠加**。于是我们做了一个大胆的减法——

**砍掉了自动绑骨模型,把流程精简到只剩一个 see-through 模型**,大大降低了方差,成功率一下就上来了。

## 二、自研 PPD 引擎:一条全新的技术路线

在砍掉绑骨的基础上,我们**自研了一套 PPD 引擎**,并围绕它搭建了完整的工作流:

> **输入一张静态图片 → 输出一个伪 Live2D 动态角色**

这条路线绕开了传统绑骨对模型质量的苛刻要求,用"图层拆解 + 支点 + 仿射变换"的思路实现角色的眨眼、呼吸、转头、摸头互动,效果稳定、成本可控。现在角色生成已经是"一张图进去,几分钟出成品"的稳定状态。

## 三、产品化进展:从"实验室"走向"能用的产品"

这段时间我们把整个系统搬到了云服务器上,并且完成了:

- **用户管理体系**:多用户注册登录、权限隔离,每个人的角色资源和数据互不干扰
- **联网自动更新**:再也不用把资源拷进 SD 卡、插进设备才能换角色了——设备联网后**自动检查、自动更新**,新增角色、换背景、换时装全部云端同步
- 管理后台、资源制作网页、手机端适配也全部就绪,普通用户零门槛使用

## 小结

一句话总结最近的进展:**技术路线跑通了(砍绑骨 + 自研 PPD 引擎),产品闭环打通了(云端 + 多用户 + 自动更新)**。下一步我们在打磨体验细节和稳定性,争取让更多同学用起来。
