## 三、数据流（板块间如何协作）

```
① PRTS wiki ──wiki_fetch.py──→ ② 仿真器转换页(/spine2ppd)
                                   │ Spine 资源 → PPD 转换 → 预览
                                   ▼
③ 导出设备包 → ⑤ 设备 SD 卡（或先放 ④ 虚拟 SD 卡在 PC 验证）
                                   │
设备启动 ──OTA(8003)──→ ③ 本地服务器 ──返回──→ ws://192.168.1.37:8000 对话
                                   │
对话中 LLM 调 MCP 工具 ──agent.start_task──→ ② 电脑 Agent 桥(7863) ──→ Claude Code
                                   │                    完成通知弹窗+回传
角色切换：设备唤醒词 → X-Agent-ID 头 → ③ agent_manager 查角色配置（agents.db）
                                   │
管理：浏览器 8003/admin（改角色人设/绑定设备/看历史）

音频旁路：设备 AudioForwarder ──XZ 协议(50000/50001)──→ 电脑（调试/采集用）
```

## 五、易混淆点提醒

- **仿真器（7861）跑在 PC**、**对话服务器（8000/8003）也跑在 PC**，但它们是两个独立项目、独立启动
- **虚拟 SD 卡**只是 PC 仿真用；设备实机读的是**实体 SD 卡**，两者文件结构相同，改完记得互相拷贝
- 固件里**唤醒词→角色 id** 映射硬编码在 `application.cc`（OnWakeWordDetected），服务器角色 id 必须与之对应（凯尔希 `0a2048...` 等）
- 服务器 `.config.yaml` 是用户配置（可改）、`config.yaml` 是默认模板（别改）
