# 数智方舟文创伴手礼 — 换灯片夜灯实现大纲(供并行 agent 执行)

> 目标:为《数智方舟》首批用户设计**有新意、价格低、可量产**的伴手礼。
> 主推方案:换灯片投影夜灯(PPD 干员剪影)。本文档是可执行大纲,另一个 agent 可直接按此调研/设计。

## 一、换灯片投影夜灯的实现原理

**本质是"图案投影灯"(logo 投影灯/剪影灯),不是投影仪**。结构:

```
LED 点光源 → 透镜(菲涅尔/平凸,把光准直为近似平行光) → 图案片(镂空/菲林) → 墙上成像
```

- 镂空处透光 = 亮部,实心处挡光 = 暗部 → 墙上出现放大剪影
- **灰度层次**三招:①多层镂空片叠放(透过层数不同→亮度不同,与 PPD 图层结构天然同构)②透明片上喷墨/UV 印灰度 ③多色 LED 分区打光
- 成像公式近似:`像大小 ≈ 图案大小 × (片到墙距离 / 光源到片距离)`

**与普通投影仪的区别(用户问过)**:
| | 投影仪 | 图案投影灯 |
|---|---|---|
| 成像 | 光电转换:DMD/LCD/LCoS 芯片把电信号→光图像 | 物理图案直接透射/遮挡成像,无成像芯片 |
| 内容 | 任意动态视频 | 固定图案(换片才能换图) |
| 结构 | 光源+成像芯片+透镜组+主板,复杂 | 光源+1~2 片透镜+图案片,极简 |
| 成本 | 数百~数千元 | 10~20 元 |
| 类比 | 放映电影 | 手电筒+剪纸照墙 |

## 二、结构设计与部件清单(立创商城可购)

```
[外壳:下筒+上筒,螺纹可调焦] → [LED 3W 暖白/彩色,带小散热铝片] → [菲涅尔透镜 F≈30mm] → [灯片槽(亚克力,可抽换)] → [出光口]
```

| 部件 | 规格 | 单价(小批量) | 采购渠道 |
|---|---|---|---|
| LED | 3W 暖白 或 RGB 三色,COB | 0.5~1.5 元 | 立创商城 C124953 类 |
| 驱动 | 电池 3×AA + 限流电阻(免驱动 IC)或 USB 5V | 1~3 元 | 立创 |
| 透镜 | 菲涅尔 F30~50mm 或平凸 Φ25mm | 1~3 元 | 立创/淘宝 |
| 灯片 | 1mm 透明亚克力 UV 喷印 或 激光切割双层 | 2~5 元/片 | 淘宝 UV 打样 |
| 外壳 | 3D 打印 / 纸管 / 亚克力管 | 2~5 元 | 嘉立创 3D 打印 |
| 合计 | | **8~15 元/件** | |

**换片设计**:灯片做成名片尺寸(54×86mm)亚克力卡,插槽抽换;每张 = 一个干员剪影,用户可收集整套——"收集你的干员"。

## 三、PPD 数据到灯片的转换管线(我方提供)

1. 从 PPD 场景导出某帧各图层渲染结果(已有渲染管线,服务器可跑)
2. 图层 → 剪影二值图(alpha>阈值为亮)或 2~3 层灰度(分层 UV 印)
3. 合成灯片矢量 SVG(轮廓 + 灰度层)→ 发 UV 打样/激光切割
4. 可选彩蛋:**双层可旋转灯片**(走马灯式):底层身体剪影固定,上层披风/发丝剪影绕轴旋转 → 投影微微飘动,与 PPD 动画数据同源

## 四、参考资源(调研后确认可参考程度)

- **立创开源广场**(oshwhub.com):搜"投影灯""logo 投影""小夜灯",有开源 PCB+结构;注意避坑:大部分用 DLP 芯片,成本高,只参考其光学结构
- **GitHub**:搜 "projection night light" / "shadow lamp";DIY 光学方案多采用聚光透镜+胶片
- **成品对标**:淘宝"星空投影灯/图案投影夜灯"零售 9.9~39.9 元,拆解思路为:菲涅尔+菲林片+单 LED,验证成本可行
- **可编辑图像型(用户强调)**:灯片用 UV 印刷 + AI 生成剪影可随时改图;外壳 3D 打印 STL 开源可改;光学参数(焦距/孔径)留文档,用户可自己换透镜换倍率

## 五、制作步骤(打样→小批量)

1. 用上述管线生成 5~10 个干员剪影灯片(选人气角色+内测贡献者指定)
2. 3D 打印外壳 2~3 版打样(调焦距/散热)
3. UV 灯片打样(验证灰度层次)
4. 小批量 50~100 件:外壳嘉立创 3D 打印 / 亚克力切割,灯片 UV 量产
5. 包装:盒子印"你的干员,关灯出现"+ 绑定码

## 六、风险与备选

- 风险:菲涅尔透镜成像边缘模糊 → 备选:平凸玻璃透镜(贵 1~2 元)或缩小图案
- 风险:LED 发热 → 3W 内+铝片即可,续航用 3×AA(约 8 小时)
- 备选方案 B(更低成本):分层亚克力立牌 + 磁吸点头(无光源,单件 8~15 元)
- 备选方案 C(旗舰):分层 + 发条音乐盒机芯驱动呼吸(单件 20~35 元,给内测贡献者)

## 七、需求清单汇总(全项目)

1. PPD 图层 → 剪影 SVG/灯片矢量导出工具(服务器脚本)
2. PPD 呼吸动画轨迹 → 凸轮轮廓数据(方案 C 用)
3. 灯片图库:10 个角色起,后续随时加
4. 所有产物**可编辑**(源文件开源给用户:SVG/STL/光学参数表)
